ℹ️ Acerca de SocialDesk

SocialDesk v1.0 — Herramienta de gestión de contenido para digital marketers.

Desarrollada como un único archivo HTML. No requiere servidor ni instalación. Todos los datos se guardan localmente en tu navegador.

Para modificar la herramienta, abre el archivo index.html con cualquier editor de código (VS Code recomendado).
